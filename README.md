# HIGH TECH PS - Offline Web Host Page

صفحة ويب مخصصة لمركز صيانة **HIGH TECH PS** لإدارة وتشغيل ثغرات وأدوات البلايستيشن (PS4 / PS5) وإمكانيّة العمل الكامل **Offline (أوفلاين)** دون الحاجة لاتصال إنترنت دائم.

---

## 🌟 الميزات الرئيسية

1. **دعم العمل أوفلاين بالكامل (Offline Caching):**
   - عند فتح الرابط لأول مرة على جهاز البلايستيشن، تقوم الصفحة عبر **Service Worker** بتنزيل وحفظ كافة الملفات تلقائياً.
   - يظهر شريط تقدم تفاعلي يحسب نسبة التخزين من **1% إلى 100%**.
   - بمجرد اكتمال العد، تظهر رسالة تفيد بإمكانية قطع إنترنت الجهاز واستخدام الصفحة بشكل مستمر أوفلاين.

2. **أحدث إصدار GoldHEN:**
   - تم تحديث الصفحة لدعم **GoldHEN v2.4b18.2**.

3. **تصميم مخصص باسم المحل:**
   - زر GoldHEN الرئيسي مصمم باسم **HIGH TECH PS** وتحته مباشرة اسم وتحديث **GoldHEN v2.4b18.2**.

4. **سجل عمليات (Console Output):**
   - شاشة لمتابعة خطوات تحميل وتنفيذ الحمولة على الجهاز لحظة بلحظة.

---

## 📁 محتويات المجلد

- `index.html`: هيكل الصفحة الواجهة الرئيسية وواجهة المستخدم.
- `style.css`: التنسيقات والألوان الثيم الخاص بمركز HIGH TECH PS.
- `cache.js`: منطق حاسبة التخزين التفاعلية واستقبال تحديثات نسبة المئوية.
- `sw.js`: الـ Service Worker المسؤول عن حفظ الصفحة أوفلاين.
- `exploit.js`: ملف إدارة وتشغيل الـ Payloads.
- `manifest.json`: إعدادات الـ Web App لدعم التثبيت المباشر على الأجهزة.
- `README.md`: هذا الملف الإرشادي.

## 🚀 طريقة الاستخدام والأول مرة على البلايستيشن

1. **الربط بالإنترنت:** قم بتوصيل بلايستيشن 4 أو 5 بالإنترنت وافتح متصفح الجهاز.
2. **فتح الرابط:** ادخل رابط الصفحة Hosted on GitHub Pages.
3. **عملية الكاش:** انتظر حتى يبدأ العد التلقائي من **1% إلى 100%** في شريط التخزين.
4. **التأكيد:** عند اكتمال العد وكتابة *"تم الكاش بنجاح! يمكنك الآن إغلاق الإنترنت"*.
5. **الاستخدام أوفلاين:** اخرج من المتصفح واقطع الإنترنت عن البلايستيشن، وستعمل الصفحة دائماً بدون إنترنت من الـ User Guide أو المتصفح.
